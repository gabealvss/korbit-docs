## Como acompanhamos mudanças

- A [API Reference](/api-reference) é gerada automaticamente da nossa especificação OpenAPI — o que está lá é o que a API faz.
- Tipos de [webhook](/webhooks/catalogo-de-eventos) são versionados: eventos novos mantêm compatibilidade; mudanças incompatíveis geram uma nova versão `.*.vN` e são anunciadas aqui com período de transição.
- Mudanças de contratos (campos novos opcionais, novos códigos de erro) não são breaking changes e aparecem aqui por release.
